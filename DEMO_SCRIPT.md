# Nimiq TipJar Demo Script (3 minutes)

## Scene 1: The Problem (0:00-0:20)
- Visual: Creator trying to receive tips
- Show: copying wallet address, switching apps, waiting for confirmation
- Text overlay: Tipping online is still too hard
- Narration: Content creators and community members often want to support each other with small payments, but existing tipping flows require leaving the app, copying wallet addresses, and paying high network fees.

## Scene 2: The Solution (0:20-0:40)
- Visual: Open Nimiq Pay app, navigate to TipJar mini app
- Text overlay: Nimiq TipJar - Instant Micro-Tipping
- Narration: Nimiq TipJar runs directly inside Nimiq Pay. No app switching, no copy-paste, no high fees.

## Scene 3: Connect Wallet (0:40-1:10)
- Visual: Click Connect Wallet button
- Show: Nimiq Pay authorization prompt
- Show: Connected address and balance appear
- Text: One click to connect. Your balance shown instantly.
- Narration: One click to connect your Nimiq wallet. Your balance and account info are displayed right away.

## Scene 4: Send a Tip (1:10-1:50)
- Visual: Enter recipient address, type tip amount, click Send Tip
- Show: Transaction confirmation in Nimiq Pay
- Text: Send micro-tips in NIM. Fast, low-fee, no copy-paste.
- Narration: Send a micro-tip in NIM. It is fast, low-fee, and requires no copy-pasting of addresses.

## Scene 5: Transaction History (1:50-2:20)
- Visual: Switch to Transaction History tab
- Show: List of past transactions with status badges
- Text: Track all your tips in one place.
- Narration: Every transaction is recorded and visible in the history tab.

## Scene 6: Tech & Code (2:20-2:45)
- Visual: Show code editor with React components
- Show: package.json with @nimiq/mini-app-sdk
- Text: Built with React 18, Vite 5, Tailwind CSS, and Nimiq Mini App SDK
- Narration: Built with modern web technologies and the official Nimiq Mini App SDK.

## Scene 7: Roadmap (2:45-3:00)
- Visual: Feature roadmap graphic
- Show: QR tipping, split payments, social sharing, leaderboard
- Logo animation
- Narration: Up next: QR code tipping, multi-recipient split payments, and social sharing.
