# Demo Video Script (3 minutes)\n\n## Scene 1: The Problem (0:00 - 0:20)\n**Visual:** Show someone trying to tip a creator\n- Copy wallet address from one app\n- Switch to another app\n- Paste address manually\n- Wait for network confirmation\n\n**Subtitle:** Tipping online is still too hard. Copy address, switch apps, pay fees. This friction kills micro-payments.\n\n---\n\n## Scene 2: Introducing TipJar (0:20 - 0:40)\n**Visual:** Open Nimiq Pay browser, navigate to TipJar mini app\n\n**Subtitle:** Nimiq TipJar runs directly inside Nimiq Pay. No copy-paste, no switching apps.\n\n---\n\n## Scene 3: Connect Wallet (0:40 - 1:10)\n**Visual:**\n- Click Connect Wallet button\n- Show account detected automatically\n- Display balance on screen\n\n**Subtitle:** One click to connect. Your balance and account are shown instantly. No setup, no extensions.\n\n---\n\n## Scene 4: Send a Tip (1:10 - 1:50)\n**Visual:**\n- Type recipient address\n- Enter tip amount (e.g., 0.5 NIM)\n- Click Send Tip\n- Show success message\n\n**Subtitle:** Send a micro-tip in NIM. Fast, low-fee, no copy-paste. Just enter amount and address.\n\n---\n\n## Scene 5: Transaction History (1:50 - 2:20)\n**Visual:**\n- Show transaction appearing in history\n- Display status: confirmed\n- Show amount and timestamp\n\n**Subtitle:** The transaction is recorded and visible in history. Full transparency, always.\n\n---\n\n## Scene 6: Tech Stack (2:20 - 2:45)\n**Visual:** Show GitHub repo and key code files\n\n**Subtitle:** Built with React 18, Vite 5, Tailwind CSS, and the Nimiq Mini App SDK.\n\n---\n\n## Scene 7: Roadmap (2:45 - 3:00)\n**Visual:** Show roadmap features and app logo\n\n**Subtitle:** Next: QR code tipping, multi-recipient payments, social sharing. Join us in building the future of micro-payments.\n\n---\n\n## Recording Tips\n1. Use screen recording software (OBS, Windows Game Bar, or phone)\n2. Keep camera steady and zoom in on important elements\n3. Speak clearly and at a moderate pace\n4. Edit out pauses and mistakes\n5. Add subtitles for clarity
