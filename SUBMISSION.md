# Nimiq TipJar - Competition Submission\n\n## Project Overview\n**Project Name:** Nimiq TipJar\n**Tagline:** Send micro-tips in NIM directly inside Nimiq Pay\n\n**Problem Statement:**\nTipping online is still too complicated. Users often need to copy wallet addresses, switch between apps, and pay high network fees. This friction makes micro-payments impractical for creators, streamers, and community members who want to support each other with small amounts.\n\n**Solution:**\nNimiq TipJar is a lightweight mini app built on the Nimiq Mini App SDK. It integrates directly with Nimiq Pay, allowing users to connect their wallet, view their real-time NIM balance, send tips to any Nimiq address, and track transaction history.\n\nBecause it runs natively inside Nimiq Pay, the experience is fast, low-fee, and beginner-friendly.\n\n## Key Features\n1. One-click wallet connection via Nimiq Pay\n2. Real-time NIM balance display\n3. Simple tipping flow with recipient address and amount\n4. Transaction history tracking\n5. Error handling and loading states\n6. Mobile-first responsive UI\n7. Built with React 18, Vite 5, Tailwind CSS, and @nimiq/mini-app-sdk\n\n## How It Works\n1. User opens the mini app inside Nimiq Pay browser\n2. User clicks Connect Wallet - the app detects existing accounts\n3. The app displays the connected account and NIM balance\n4. User enters a recipient address and tip amount\n5. The app sends the transaction through the Nimiq Mini App SDK\n6. The transaction appears in the history section\n\n## Why This Matters\nNimiq is designed for fast, low-cost payments. TipJar turns that into a social micro-economy tool. It lowers the barrier for creators and community members to support each other instantly.\n\n## Roadmap\n- QR code tipping\n- Multi-recipient split payments\n- Social sharing to X / Telegram\n- Leaderboard for top supporters\n- Fiat on-ramp integration\n- Multi-language support\n\n## Live Demo\n- App: https://temporary-turbo-krypton-u3sf32f.vercel.app\n- GitHub: https://github.com/Zhiyilang074811/nimiq-tipjar\n\n## Team\nStitch - CSDN 3000+ follower blogger, AI x Web3 builder.
